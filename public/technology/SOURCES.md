# Technology logo sources

Source collection: [Devicon](https://github.com/devicons/devicon), pinned release **v2.17.0**.

Each SVG is stored locally without recoloring or modifying its paths. The original variants are used to identify the corresponding technologies. Visible text labels remain beside each logo. No runtime request to a third-party logo service is required.

Source URL pattern: `https://raw.githubusercontent.com/devicons/devicon/v2.17.0/icons/{directory}/{directory}-original.svg`.

The collection license is preserved in `DEVICON-LICENSE.txt`. Brand ownership and policies remain with the respective owners; these marks identify technologies, not an endorsement of this portfolio. Devicon's [README](https://github.com/devicons/devicon#about-the-project) states its identification purpose and points to the respective brand policies. Collection licensing does not establish blanket trademark permission. Keep assets unaltered and review brand requirements if the use or presentation changes.

Java uses the collection's actual Java artwork, not a generic substitute. Spring Boot uses the Spring ecosystem mark with the explicit Spring Boot text label. Technology-to-project associations are separately documented in `app/data/technology.ts`; downloading a logo does not add a skill or prove its use in a project.
